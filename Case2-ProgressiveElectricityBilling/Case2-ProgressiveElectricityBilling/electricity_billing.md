# Case Study 2: Progressive Electricity Billing

## Aim
To develop a Python program to calculate electricity bills using progressive tariff rates.

## INPUT
- Customer name
- Electricity units consumed

## PROCESS
1. Read the customer name and units consumed.
2. Calculate charges according to the applicable unit slabs.
3. Add the charges from each slab.
4. Display the total electricity bill.

## OUTPUT
- Customer name
- Units consumed
- Total electricity bill

## Algorithm
1. Start.
2. Input customer name and units consumed.
3. Calculate the bill using progressive tariff slabs.
4. Display the total bill.
5. Stop.

## Pseudocode
START
INPUT customer_name
INPUT units
CALCULATE bill using progressive slabs
DISPLAY customer_name
DISPLAY bill
STOP

## Flowchart
